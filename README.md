# Python CLI Projects

A collection of Python command-line applications built to practise Python programming, problem-solving, and core programming concepts.

This repository contains beginner-friendly projects developed while learning Python. Each project focuses on applying different concepts through practical implementation.

## Projects

### 1. ATM Simulation
A simple ATM application that simulates basic banking operations.

**Features:**
- PIN verification
- Balance checking
- Cash withdrawal
- Deposit money
- Input validation

**Concepts Practised:** Conditional statements, loops, functions, variables, and input validation.

### 2. Number Guessing Game
An interactive game where the user tries to guess a randomly generated number.

**Features:**
- Random number generation
- User guesses and feedback
- Input validation
- Option to play again

**Concepts Practised:** Random module, loops, conditional statements, functions, and exception handling.

### 3. Quiz Game
A category-based quiz application that tests general knowledge and saves quiz results.

**Features:**
- Multiple quiz categories
- Randomised questions
- Score calculation
- Save quiz results to a text file
- Leaderboard functionality

**Concepts Practised:** Lists, dictionaries, functions, randomisation, file handling, and sorting.

### 4. Shopping Cart
A command-line shopping cart application that allows users to manage products and generate bills.

**Features:**
- Add products to cart
- View shopping cart
- Remove and update items
- Apply discount coupons
- Calculate GST
- Generate and save bills

**Concepts Practised:** Dictionaries, lists, functions, loops, calculations, file handling, and input validation.

### 5. Spin Game
A slot-machine-style game where users place bets and try their luck with random spins.

**Features:**
- Randomised slot results
- Betting system
- Winning and payout calculation
- Balance tracking
- Game summary

**Concepts Practised:** Random module, dictionaries, functions, loops, conditional statements, and calculations.

### 6. Rock Paper Scissors

A classic Rock Paper Scissors game where users compete against the computer in a Best of 5 tournament.

**Features:**

- Player vs Computer gameplay
- Randomised computer choices
- Input validation
- Winner detection
- Best of 5 tournament
- Score tracking
- Final match result
- Replay option

**Concepts Practised:** Random module, functions, lists, while loops, conditional statements, user input, return statements, and score management.

### 7. Tic Tac Toe

A classic two-player game where players take turns marking X and O on a 3×3 board. The first player to get three marks in a row, column, or diagonal wins.

**Features:**

- Two-player gameplay
- 3×3 game board
- Alternating player turns
- Position selection
- Invalid input validation
- Prevention of occupied positions
- Winner detection
- Draw detection
- Replay option

**Concepts Practised:** Nested lists, indexing, functions, while loops, conditional statements, input validation, and game logic.

## Technologies Used

- **Language:** Python
- **Libraries:** Python Standard Library
- **Tools:** VS Code, Git, GitHub

### Prerequisites

- Python 3 installed
- A code editor or terminal

### Run a Project

1. Clone the repository:

```bash
git clone https://github.com/ArpitaSaha2004/Python-CLI-Projects.git
```

2. Open the project directory:

```bash
cd Python-CLI-Projects
```

3. Navigate to the project you want to run. For example:

```bash
cd ATM
```

4. Execute the Python file:

```bash
python3 atm.py
```

Follow the same process for the other projects using their respective Python filenames.
